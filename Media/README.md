# 🎥 IRIS Media Library

This folder contains short video clips demonstrating different aspects of the **IRIS** project.


1. **IRIS_overview.mp4** - A self-contained overview of IRIS, including motivation, experimental results, and a live demonstration, with English and Chinese subtitles.
2. **demo.mp4** - Full demonstration of IRIS in action — from transmission to authentication result.
3. **data-collection-facility.mp4** - The data collection facility in action.
4. **short-demo.mp4** - A fast-paced demonstration of IRIS in action, correctly identifying each of the receivers.
5. **3dprinting-facility.mp4** - See how the IRIS data collection facility was produced using 3D printing.
